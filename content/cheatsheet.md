# Cheatsheet: cola rápida do Vim

**Referência rápida:** para aprender a trilha em ordem, comece pelo
[Módulo Linux — Terminal básico](terminal-basics.md) e depois siga para
[Módulo Vim — Primeiros passos](getting-started.md).

Pressione `Esc` antes de usar os comandos abaixo.

| Tarefa | Comando |
| :--- | :--- |
| Inserir antes/depois do cursor | `i` / `a` |
| Nova linha abaixo | `o` |
| Sair do modo atual | `Esc` |
| Salvar / sair / salvar e sair | `:w` / `:q` / `:wq` |
| Sair sem salvar | `:q!` |
| Mover | `h` `j` `k` `l` |
| Próxima/anterior palavra | `w` / `b` |
| Início/fim da linha | `0` / `$` |
| Início/fim do arquivo | `gg` / `G` |
| Remover caractere/linha | `x` / `dd` |
| Copiar/colar linha | `yy` / `p` |
| Desfazer/refazer | `u` / `Ctrl-r` |
| Buscar e avançar/voltar | `/texto`, `n`, `N` |
| Substituir no arquivo | `:%s/antigo/novo/gc` |

## Regra de ouro

Se não souber em qual modo está ou algo der errado, pressione `Esc`. Se você
alterou algo sem querer, pressione `u`.
