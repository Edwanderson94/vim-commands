## Definição do Vim e alternativas

- [Vim — About](https://www.vim.org/about.php), site oficial do projeto. Descreve o Vim como editor de texto configurável, derivado do Vi, para editar diferentes tipos de texto.
- [Vim Reference Manual — Introduction](https://vimhelp.org/intro.txt.html), documentação oficial do Vim. Explica o nome “Vi IMproved” e apresenta o Vim como editor para texto simples e programas.
- [Ubuntu Manpage — vim(1)](https://manpages.ubuntu.com/manpages/noble/man1/vim.1.html). Documentação Linux que descreve a abertura com `vim arquivo` e o uso para editar texto simples.
- [Debian Wiki — Vim](https://wiki.debian.org/vim). Guia prático da comunidade Debian sobre Vim no terminal e seus modos normal e de inserção.
- [Debian — pacote nano](https://packages.debian.org/stable/editors/nano), [Emacs](https://packages.debian.org/stable/editors/emacs) e [Micro](https://packages.debian.org/stable/editors/micro). Exemplos de outros editores de texto disponíveis no ecossistema Debian/Linux.

Consultadas em 24 out. 2026. Essas fontes fundamentam o resumo introdutório
da página inicial: Vim é um editor de texto que pode ser usado no terminal,
funciona em diferentes sistemas e é uma entre várias opções de editor.

## Curiosidades apresentadas na página inicial

- [Vim User Manual — Using the Vim tutor](https://vimhelp.org/usr_01.txt.html#vimtutor). Documenta o `vimtutor`, prática interativa de cerca de 30 minutos em duas partes, iniciada com `vimtutor` no terminal Unix.
- [Vim Reference Manual — Spell checking](https://vimhelp.org/spell.txt.html#spell). Documenta a verificação ortográfica ativada pela opção `spell` e esclarece que o recurso verifica ortografia, não gramática.
- [Vim User Manual — Write plugins](https://vimhelp.org/usr_51.txt.html#write-plugin). Explica que plugins e scripts podem personalizar e ampliar o Vim.

Consultadas em 24 out. 2026. A página resume esses recursos em linguagem
introdutória; a disponibilidade de dicionários e recursos específicos pode
depender da instalação do Vim.

- aalvesjr. [Comandos VIM](https://gist.github.com/aalvesjr/1290585). GitHub Gist, criado em 16 out. 2011. Acesso em 24 out. 2026.

  Referência consultada para os modos do Vim e os comandos de inserção e saída,
  incluindo `i`, `Esc`, `:q!` e `:wq`. O simulador implementa apenas o escopo
  educacional definido em [specification.md](specification.md); a lista ampla do
  Gist não representa comandos disponíveis no simulador.
