# Direção do frontend

- Seguir as seções de site e simulador em `specification.md` antes de criar
  ou alterar arquivos em `site/`.
- Manter o site estático, com HTML semântico, CSS responsivo e JavaScript modular.
- Usar caminhos relativos para viabilizar GitHub Pages.
- Garantir uso por teclado, foco visível, contraste adequado e mensagens de estado em texto.
- Não capturar teclas globais: o Vim simulado só recebe entradas depois que o
  aluno abre um arquivo com `vim` no terminal e enquanto o editor está focado.
- Não introduzir bibliotecas, rastreamento, autenticação ou acesso a arquivos locais sem pedido explícito.
- Validar links, HTML e o comportamento manual básico antes de considerar uma entrega concluída.
