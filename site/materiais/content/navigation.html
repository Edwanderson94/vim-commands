Navegação no Vim

No modo normal, você move o cursor sem precisar das setas. Comece devagar: os comandos abaixo parecem pequenos, mas são usados o tempo todo.

Movimento básico

ComandoAção
hMove um caractere para a esquerda.
jMove uma linha para baixo.
kMove uma linha para cima.
lMove um caractere para a direita.
wVai ao início da próxima palavra.
bVai ao início da palavra anterior.
0Vai ao início da linha.
$Vai ao fim da linha.
ggVai à primeira linha do arquivo.
GVai à última linha do arquivo.
:25Vai diretamente à linha 25.

Repetições

Coloque um número antes de muitos comandos para repeti-los. Por exemplo:

  • 5j desce cinco linhas.
  • 3w avança três palavras.
  • 10G vai para a linha 10.

Pratique

Abra um texto com várias linhas. Use gg para ir ao começo, G para ir ao fim e :número para visitar uma linha específica. Depois, tente chegar ao fim de uma linha apenas com $.
