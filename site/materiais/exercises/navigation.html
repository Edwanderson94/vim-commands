Exercício: navegação

Pré-requisito: conclua Módulo Linux — Terminal básico, Primeiros passos no Vim e Navegação.

Abra qualquer arquivo de texto com pelo menos dez linhas. Faça as tarefas sem usar as setas do teclado.

  1. Vá para a primeira linha com gg.
  2. Desça cinco linhas com 5j.
  3. Vá para o fim da linha com $.
  4. Volte ao início da linha com 0.
  5. Vá para a última linha com G.
  6. Volte para a linha 3 com :3 e Enter.

Conclusão

Você concluiu o exercício se conseguiu chegar a cada posição somente com os comandos do Vim.
