Informações sobre o Vim

Ordem para aprender: comece pelo Módulo Linux — Terminal básico e depois siga para o módulo de Vim nas aulas abaixo. O Vim é um editor de texto usado no Linux e em outros sistemas; não é o sistema operacional. Você o abre a partir do terminal.

O que é o Vim?

Vim (de Vi IMproved) é um editor de texto modal: um aplicativo para criar e modificar arquivos, como programas e arquivos de configuração. “Modal” quer dizer que as teclas fazem coisas diferentes conforme o modo ativo. O Vim é muito usado no terminal do Linux, mas não é o sistema operacional Linux: também funciona em outros sistemas e tem uma versão gráfica chamada gVim.

O terminal e o Vim são coisas diferentes: no terminal você digita vim arquivo.txt para abrir o arquivo; dentro do Vim, você edita o texto. Pressione i para entrar no modo de inserção e digitar. Pressione Esc para voltar ao modo normal e usar comandos de edição.

Vim é uma entre várias opções. No Linux também existem editores como Nano, Emacs e Micro. Cada um tem seus próprios comandos e jeito de trabalhar; esta trilha ensina Vim.

Curiosidade 1: o Vim tem um tutor interativo

Se o Vim estiver instalado, digite vimtutor no terminal. Você abre uma prática guiada de cerca de 30 minutos, dividida em duas partes, e aprende experimentando os comandos.

Fonte: manual oficial do Vim — uso do tutor.

Curiosidade 2: ele pode conferir a ortografia

Com um dicionário disponível para o idioma, digite :set spell dentro do Vim para destacar palavras que parecem estar escritas incorretamente. O recurso verifica ortografia, mas não gramática.

Fonte: manual oficial do Vim — verificação ortográfica.

Curiosidade 3: dá para ampliar e personalizar

Configurações, scripts e plugins podem adaptar o Vim e acrescentar recursos. Um plugin pode, por exemplo, adicionar comandos ou integrar ferramentas ao editor.

Fonte: manual oficial do Vim — plugins.

Pratique no terminal

Você está em /home/aluno. No terminal, use apenas pwd, ls, cat arquivo, clear e vim arquivo. Digite vim teste.txt nesta janela e pressione Enter. O comando clear limpa a tela sem apagar arquivos. No Vim, pressione i para inserir texto e Esc para voltar ao modo normal. Use :q e Enter para sair sem alterações pendentes, :wq para salvar e sair ou :q! para descartar alterações. Use cat teste.txt no terminal para ler o arquivo salvo. Os arquivos ficam somente nesta página.
