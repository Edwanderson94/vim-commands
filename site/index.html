Pratique com segurança

Use primeiro o terminal simulado. Os comandos e arquivos ficam apenas nesta página; nada é executado no computador. No Vim, use o teclado somente dentro da área de prática. A tecla Tab continua movendo o foco pelos controles.

Terminal simulado

Digite help para ver os comandos. Exemplo: mkdir -p ~/vim-pratica, cd ~/vim-pratica, vim ola.txt.

O editor abaixo simula o Vim; os comandos digitados nele são diferentes dos comandos do terminal.

Modo: NORMAL

O Vim simulado cobre inserção (i, a, o, Esc), navegação, edição, busca e os comandos Ex :w, :q, :q! e :wq.
